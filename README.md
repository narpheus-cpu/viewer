# 전자책뷰어 + ChatGPT

본문을 드래그해 선택하면 **ChatGPT연결** 메뉴가 나타납니다. APK에서는 **복사·공유 등이 있는 Android 기본 선택 메뉴의 ChatGPT연결**을 누릅니다. APK에서 터치가 막히던 중복 HTML 버튼은 표시하지 않습니다.

답변은 팝업 맨 위의 넓은 영역에 표시됩니다. 계정·모델·프롬프트는 아래의 접힌 **설정**을 열어 변경합니다. 질문을 보내면 설정은 자동으로 접힙니다.

팝업에서 ChatGPT 계정, 계정별 제공 모델, 프롬프트를 선택하고 **질문 보내기**를 누르면 선택한 본문에 대한 답변을 읽을 수 있습니다. 프롬프트와 모델 선택은 같은 기기·브라우저에 저장됩니다. 프롬프트에 `{{본문}}`을 넣으면 그 자리에 선택 문장을 넣으며, 없으면 프롬프트 뒤에 선택 본문을 덧붙입니다. 질문 보내기를 누르기 전에는 본문을 전송하지 않습니다.

## APK

처음 사용할 때 **Continue with ChatGPT**를 눌러 시스템 브라우저에서 로그인하고 이 앱의 ChatGPT 구독 사용 권한을 승인한 뒤 뷰어로 돌아오세요. 로그인 이후에는 뷰어 안의 팝업에서 답변을 읽습니다. 계정별로 제공되는 모델을 불러오므로 임의의 모델명을 고정하지 않습니다.

## PC / HTML

1. PC 연결 프로그램 ZIP을 풀고 `connector/START_ChatGPT.bat`를 실행합니다. 이 PC에는 Node.js가 설치되어 있습니다. 다른 PC에서는 Node.js 22 이상이 필요합니다.
2. 자동으로 열린 로컬 뷰어에서 책을 열고 문장을 선택합니다.
3. **ChatGPT연결 → Continue with ChatGPT**로 로그인·사용 권한 승인을 마치면 팝업에서 질문할 수 있습니다.

실행 창을 닫으면 PC 연결이 종료됩니다. 다음 사용 때 시작 파일을 다시 실행하세요. 실행 창을 닫아도 프롬프트·계정 등록은 유지됩니다.

GitHub의 웹 뷰어를 계속 쓰려면 연결 프로그램 실행 후 뷰어 팝업의 **PC 연결**을 눌러 연결 창에서 승인하세요. 브라우저가 로컬 네트워크 연결 권한을 물으면 허용해야 합니다. 다운로드한 HTML 파일을 직접 여는 경우에는 시작 파일이 여는 로컬 뷰어를 사용하세요.

로컬 뷰어와 GitHub 뷰어의 책 내역·프롬프트 저장소는 브라우저 주소별로 별개입니다. 다른 기기와의 자동 동기화는 제공하지 않습니다.

## 계정 및 요청 처리

이 기능은 OpenAI의 오픈소스용 Sign in with ChatGPT 흐름을 사용합니다. 별도의 OpenAI API 키를 입력하는 방식이 아닙니다. 사용 가능한 모델과 구독 사용량은 로그인한 계정의 권한·한도를 따릅니다. 기존 ChatGPT 대화나 메모리는 이 기능에 자동으로 전달되지 않습니다.

OAuth 액세스·갱신 토큰은 HTML이나 브라우저 저장소에 넣지 않습니다. APK는 Android Keystore로 암호화한 앱 내부 저장소, Windows 연결 프로그램은 현재 Windows 사용자용 DPAPI로 보호한 저장소를 사용합니다. PC 연결은 127.0.0.1에만 열고 브라우저 연결 키·허용 출처를 확인합니다. 모델·프롬프트·선택 본문은 공개 저장소에 저장되지 않습니다.

답변 스트림의 `response.completed`를 확인해야 완료로 표시합니다. 중지·연결 끊김·사용량 오류는 별도로 표시하며 실패한 질문을 자동 재전송하지 않습니다. 로그아웃 시 갱신 토큰 폐기를 시도하고, 원격 해제를 확인하지 못하면 화면에 안내합니다.

## 검증 범위

문장 드래그, 선택 부분만 전송, 프롬프트·모델 재사용, 팝업 크기, 중지·뒤로가기와 기존 읽기 기능을 브라우저에서 검사했습니다. OAuth 서명·상태·PKCE·갱신·모델·스트림·출처 검사는 모의 서버 응답으로 확인했습니다. APK의 Java 컴파일과 Android DEX 변환을 확인했습니다.

빌드 환경의 로컬 네트워크 제약으로 실제 계정 로그인과 실제 Poke2 설치 검증은 수행하지 않았습니다. 첫 실행에서 실제 계정으로 로그인해 연결 상태를 확인하세요.


### 모바일 웹의 ChatGPT 계정 연결과 기본 선택 메뉴

모바일 웹은 같은 휴대폰에 설치한 기존 전자책뷰어 앱의 ChatGPT 연결을 사용합니다.
PC 연결 프로그램이나 별도 계정 저장소는 사용하지 않습니다.

1. [전자책뷰어 v1.26 업데이트](downloads/EbookViewer_v1.26.apk)를 기존 v1.18에 덮어설치합니다.
   앱의 패키지·서명·저장소 주소를 유지하므로 기존 계정·모델·프롬프트·책 내역을 그대로 사용합니다.
2. 모바일 웹을 새로고침하고 설정의 **전자책뷰어에서 계정 연결**을 누릅니다.
   앱의 계정·모델·프롬프트 설정이 열립니다. 업데이트 전에는 설치 파일로 안내합니다.
3. 웹 본문에서 문장을 선택한 뒤 기본 메뉴의 **ChatGPT연결 · 뷰어**를 누릅니다.
   메뉴가 좁으면 더보기(⋮)에 있습니다. PROCESS_TEXT를 지원하는 Android 브라우저가 필요합니다.
4. 선택 문장만 기존 앱의 팝업으로 전달되며 **질문 보내기**를 누르면 답변이 위에 표시됩니다.
   닫으면 원래 브라우저 탭으로 돌아갑니다. 웹의 책과 읽던 위치는 유지됩니다.

기존 연결용 앱 `ChatGPT_Menu_Bridge_v1.0.apk` 대신 전자책뷰어 자체를 업데이트하는 방식입니다.
기본 메뉴 항목에 **· 뷰어**를 붙여 별도 연결 앱의 항목과 구별합니다.
계정 연결용 주소에는 본문·토큰을 넣지 않으며, 선택 문장은 Android 텍스트 처리 기능으로만 전달합니다.
HTML만으로 ChatGPT 구독 계정의 로그인·추론을 직접 수행하도록 구현한 것이 아닙니다.
APK의 기존 네이티브 연결 코드를 사용하며, 데스크톱 웹의 PC 연결 방식은 유지됩니다.


### GPT 답변 페이지 넘김

답변 영역의 왼쪽을 짧게 터치하면 이전 페이지, 오른쪽을 터치하면 다음 페이지를 표시합니다.
상단에 `[현재/전체] 페이지`를 표시하며 아래의 이전·다음 버튼과 키보드 방향키도 사용할 수 있습니다.
드래그 선택·길게 누르기·설정 및 버튼 조작은 페이지를 넘기지 않습니다.
답변 수신 중에는 읽던 페이지를 유지하고, 화면 크기·설정 펼침이 바뀌면 같은 글자 위치를 포함한 페이지로 맞춥니다.

### GPT 답변 마크다운

제목·굵게·기울임·취소선·목록·인용·표·코드 블록을 표시합니다. 좌우 터치 페이지 넘김은 유지하고 긴 코드 줄은 화면 너비에 맞춰 줄을 바꿉니다. 링크를 누르면 새 창으로 열며 페이지는 넘기지 않습니다. 렌더러는 HTML/APK에 포함되어 별도 다운로드가 필요하지 않습니다. 원시 HTML은 실행하지 않고 이미지 주소는 자동으로 불러오지 않습니다.

### 비교 연표 (v1.24)

본문의 연도를 회색 음영·점선으로 표시합니다. 짧게 누르면 책 페이지가 넘어가고 0.55초 이상 길게 누르면 비교 연표가 열립니다. 서기·기원후·AD·A.D.·CE·C.E.와 기원전·BC·B.C.·BCE·B.C.E.의 대소문자·공백·연도 앞뒤 표기를 인식합니다. 기원전과 기원후를 구별하고 0년을 만들지 않습니다. 기존 각주와 연도가 겹치면 연표를 우선합니다. 세기·C 표기는 연도로 연결하지 않습니다.

제공한 TXT 22개에서 분리한 456개 연도·세기 구간을 기본으로 제공합니다. 세기 범위 안의 연도는 해당 구간을 열고 수록되지 않은 연도는 가장 가까운 항목을 엽니다. 요청 연도와 실제 항목은 팝업에 표시됩니다. 연표는 본문과 별도로 저장하며 전체 연표를 다시 읽거나 전체 페이지 수를 계산하지 않습니다. 한 번에 최대 21페이지를 구성하고 경계에서 이전·다음 구간을 읽습니다. 가까운 항목만 캐시합니다.

[설정 → 비교 연표 → 연표 TXT / ZIP 등록]에서 다른 연표를 등록할 수 있습니다. 여러 TXT와 TXT가 든 ZIP을 지원하며 기기·브라우저별로 저장됩니다. 연도 제목은 독립된 줄에 쓰세요. 예: `기원전 1년`, `기원후 1년`, `C.E. 252년`. 기본 연표의 `[CE-Y0252]`·`[BCE-C050]` 형식도 지원합니다. 새 파일의 연도 제목을 찾지 못하거나 저장에 실패하면 기존 연표를 유지합니다.

APK와 웹을 함께 업데이트하세요. 모바일 웹의 GPT 답변은 설치된 APK에서 열립니다. 연표는 웹과 APK가 각각 보관하므로 직접 등록한 연표는 사용하는 쪽에서 한 번 등록해야 합니다. 기본 연표는 앱에 포함되며 웹은 열었던 구간을 저장합니다. HTML을 파일로 직접 열 경우 TXT/ZIP 등록을 사용하거나 PC 연결 프로그램으로 실행하세요. PC ZIP은 연표 자료 폴더를 함께 보관해야 합니다.

검증에는 업로드한 ZIP의 전체 456개 항목 등록, 기원전·기원후 경계, 긴 항목의 연속 구간, 터치·길게 누르기·선택·작은 화면·회전·재실행·책 위치 보존이 포함됩니다. 실제 Poke2 기기의 체감 속도는 확인하지 못했습니다.

### v1.24 수정

APK의 내부 자산 허용 목록에 연표 색인·분할 JSON 경로를 추가하고 JSON MIME으로 제공합니다. 자료가 APK에 포함되어도 앱이 차단하던 오류를 수정했습니다. 허용 경로는 기본 색인과 분할 자료로 제한하고 외부 네트워크와 임의 파일은 계속 차단합니다. 실제 MainActivity 자산 처리 메서드로 모든 내장 자료의 상태·MIME·원본 일치 및 잘못된 경로 차단을 검사합니다.

본문의 `기원전 6세기`, `6 C`, 세기 범위와 century 표기는 연도 링크에서 제외합니다. 기존 각주가 붙은 연도는 기원전·기원후를 구별해 연표를 우선하고, 연도가 아닌 단어의 각주는 기존 동작을 유지합니다.

### v1.25 세기와 연도 구분

- 본문의 `기원전 10세기`, `기원전 11세기`, `BC 11 C.`는 개별 연도 링크에서 제외합니다. 숫자와 `세기`가 페이지나 문단 경계에서 갈라져도 인접 문맥으로 확인합니다.
- TXT의 표식 없는 세기 제목도 구간으로 등록합니다. 기원전 11세기는 1100~1001년, 기원전 10세기는 1000~901년입니다. 해당 범위에 속한 본문 연도는 그 세기 항목으로 연결됩니다. 정확한 연도 항목이 함께 있으면 해당 연도를 우선합니다.
- `[BCE-Y0010] 기원전 10세기`처럼 연도/세기 표식과 제목이 충돌하면 오류를 표시하고 기존 등록 연표를 유지합니다.
- 기본 연표 456개 항목의 구간을 검사했습니다. 연표 내용과 기본 데이터 버전은 유지합니다. 화면에 표시되는 부분의 인접 문맥만 확인하며 책 전체를 다시 분석하지 않습니다.

- 차례 선택 팝업에 `닫기` 버튼을 추가했습니다. 선택하지 않고 닫거나 Escape/Android 뒤로가기를 누르면 현재 페이지와 읽던 위치를 그대로 유지합니다.

### v1.26 기본 연표 교체

사용자가 제공한 `개선 연표.zip`의 TXT 22개, 연도·세기 항목 456개로 기본 연표를 교체했습니다. 본문 데이터는 15개 구간으로 나눠 필요한 부분만 불러옵니다. 기본 연표 색인과 요청 주소에 데이터 버전을 적용해 이전 캐시와 구분합니다.

기본 연표를 사용 중이면 새 웹 또는 APK를 열 때 자동 갱신됩니다. 직접 등록한 사용자 연표를 기본 연표로 바꾸려면 `설정 → 비교 연표 → 기본 연표 사용`을 선택합니다. 책의 읽던 위치는 유지됩니다.

유지보수: 원본 TXT를 `{name,text}` 배열의 UTF-8 JSON으로 준비한 뒤 `node tools/build-timeline.cjs <sources.json>`과 `python tools/embed-timeline.py`를 실행하면 웹·APK 데이터와 버전이 함께 갱신됩니다.

### HTML 전용: 창 복귀 시 재로딩 방지

다른 창·탭을 보다가 돌아오거나 뒤로가기 캐시에서 복귀할 때 현재 DOM·페이지 배열·읽던 위치를 유지합니다. 백그라운드의 임시 화면 크기는 페이지 재분할에 사용하지 않고, 복귀 후 화면 크기가 안정된 경우에만 실제 레이아웃 변경을 처리합니다. 창 크기가 그대로면 책을 다시 읽거나 로딩 화면을 표시하지 않습니다. APK 소스와 배포 파일은 변경하지 않습니다.
